## Release scope

v0.6.0 is a **web/source release** of the desktop-first, reference-only Visual Research Workstation. GitHub source, the version tag/release and GitHub Pages are the selected publication surfaces. Remote publication and rendering must be established by the release receipt; this document defines scope without asserting those steps have completed.

### Included

- Existing generalized male BodyParts3D and female HRA anatomy: 33 and 22 semantic groups respectively.
- Central 4:3 viewport, collapsible controls and contextual learning through Learn below Lab.
- Scientific, holographic and bounded materialization presentations over unchanged source meshes.
- Selection, visibility, isolation, camera and attribution behavior, plus desktop pan/cancellation and reduced-motion controls.
- Semantic-cube branding and actual reference-viewer screenshots.

## Evidence and limitations

The earlier local visual candidate established bounded reference rendering, semantic ownership, multi-primitive materialization, visibility, input and learning behavior. The final reference-only build has a separate inventory and receipt; earlier CT-inclusive build hashes and sizes do not describe it.

Desktop Edge/WebGPU is the observed research platform. Other browsers/devices, peak driver/process memory, clinical accuracy and universal anatomy coverage are not qualified by these checks. Original reference geometry remains large: approximately 47.35 MB male and 67.54 MB female before HTTP overhead.
