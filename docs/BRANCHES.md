# Branch ownership

- `main` contains the public source and feeds the Live Demo deployment.
- `recovery` retains the v0.5.1 installation recovery baseline. The [v0.5.1 release](https://github.com/KennethJSmithDev/DICOM3D/releases/tag/v0.5.1) identifies the published artifacts.
- `experimental` retains historical prototype commits outside the public release line.

Short-lived topic branches can be retired once their changes are integrated or superseded and their required history is retained. Use release tags and artifact checksums to identify published versions.
