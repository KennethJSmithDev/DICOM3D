# Expanded BodyParts3D atlas

These fifteen chunks derive from BodyParts3D 4.0 and the 4.3i BP51212 export.

The hash-pinned chunk manifests preserve historical source notices for provenance. This file records the current distribution terms.

Changes include grouping source elements by owner, OBJ to glTF conversion, millimetres to metres with axis mapping (X,Y,Z) to (X,Z,-Y), and display materials. The per-chunk manifests retain source provenance and original owner identifiers. 4.3i source archive SHA-256: ee0dda4ff9ec8e7bb966d0eeb11df92b736c5351b73cbb1757d038b1a0bd5ead.
